## 快速运行

1. 使用微信开发者工具导入此文件夹。
2. 默认 AppID 为 `touristappid`。若工具要求测试号，请使用自己的测试号；正式发布需自己的小程序账号。
3. 编译运行，浏览商品、查看大图并尝试加购。
4. 打开地址或结算页，阅读用户服务协议和隐私政策，主动勾选并同意后再填写测试联系人。拒绝授权仍可浏览商品。
5. 选择快递或自取并创建模拟订单。示例活动为五折，折后商品合计满69元包邮，不满69元邮费5元，自取免运费。
6. 默认显示顾客界面。需要体验本地店主管理时，将 `miniprogram/config.js` 中的 `demoAdminEnabled` 改为 `true`，再从“我的 → 演示店铺管理”进入。此开关只用于本地模拟；正式权限由服务端管理员名单控制。

活动金额及配送规则均为功能示例，实际经营需自行配置。

## 配置自己的店铺

- 店铺名称、客服与运行模式：`miniprogram/config.js`。
- 演示商品：`miniprogram/data/products.js`；云端初始商品：`cloudfunctions/commerce/seed-products.json`。
- 折扣与配送规则：前后端各自的 `business.js`，须同步修改。`SHIPPING_FEE_CENTS` 可在服务端覆盖邮费，未设置时使用该文件中的示例邮费。
- 协议内容：`miniprogram/data/legal.js`。这里是本地演示说明，部署前须填入自己的主体、隐私联系方式及实际处理方式。启用云端订单前，应同步更新信息类型、保存规则、第三方说明及前后端 `consent-version.js`。
- 云端环境、管理员和支付参数：通过部署平台的服务端环境变量设置。私钥、API密钥、管理员真实标识及真实业务资料不要放进公开仓库。
- 列表图与详情图分别配置；分包内图片先复制到客户端可读文件再预览。

建议在自己控制的私有部署副本中填写真实经营资料，公开仓库始终保留示例数据。`.gitignore` 排除了表格、日志、私钥和本机配置；`tests/check-public-data.js` 检查常见敏感内容与数据边界，提交前仍需人工复核。

## 正式交易前

真实支付默认关闭。还需自己的账号、支付商户绑定、云环境与管理员配置、真实商品售卖单位核对、配送设置及真机联调。代码包含平台订单发货及收货核验、自动关单入口；部署者仍须配置发货接口、定时任务和对应平台设置。退款当前需在商户平台办理，代码查询同步退款状态。

代码公开不代表项目已经可以直接收款营业。

## 微信发货与订单自动取消

云函数目录的 `config.json` 声明官方发货接口权限。采用云调用时，通过微信开发者工具上传并部署后，权限更新可能有10分钟缓存；也可在服务器端配置自己的 `WX_APPID`、`WX_APP_SECRET` 使用官方HTTP接口。请以实际接口返回为准，不把源码已配置视为已经可调用。

在云端设置 `ENABLE_ORDER_SHIPPING=true`，发货按钮会同步微信发货信息。顺丰联系方式仅发送手机号末四位，其他快递只发送必要订单及物流信息。管理员只能给真实已付款商品订单发货，支付测试订单不能发货。

自动关单需要云端配置 `ORDER_MAINTENANCE_TOKEN` 为随机64位十六进制字符串，创建名为 `commerce-order-expiry` 的定时触发器，Cron为 `0 */1 * * * * *`，将相同令牌作为触发器CustomArgument；仅在任务存在并启用后设置 `ORDER_EXPIRY_TIMER_ENABLED=true`。维护令牌不能放进前端或提交Git。定时函数只接受该私有令牌，顾客不能冒充维护任务。

`ADMIN_OPENIDS` 只能存云函数环境变量；公开模板没有任何已绑定店主。真实付款及平台支付权限、发货权限需要在你自己的微信账号和商户中完成配置，公开示例不会替你自动开通。
